# mars_yard_benchmark

Evaluation harness (Python).

- `config/scenarios.yaml`: 20 start/goal pairs on Mars, 5 each `flat`, `slope`, `rocks`, `sand` (generated by `tools/make_scenarios.py`).
- `sim_reset.py`: teleport → settle → EKF `/set_pose` → clear hazards and costmaps → reset metrics.
- `run_benchmark.py`: one CSV row + one MCAP bag per run; failure types `timeout`, `stuck`, `collision`, `tipover`, `aborted`. Resumable.
- `analysis.py` / `robustness_analysis.py`: tables and plots. A Nav2 `SUCCEEDED` with ground-truth goal error > 1.0 m counts as `goal_miss`.

Drivers: `tools/run_matrix.sh` (Phase 6 benchmark), `tools/run_robustness.sh` (Phase 7 randomization levels).
