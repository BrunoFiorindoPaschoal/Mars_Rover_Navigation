# mars_yard_worlds

- `worlds/flat.xml`: flat test ground.
- `worlds/mars.xml`: Jezero crater patch from HiRISE DTM `DTEEC_045994_1985_046060_1985_U01`, generated by `tools/make_mars_world.py` (do not edit by hand): heightfield, collision tiles, 40 rocks, 8 boulders, 3 sand patches.
- `terrain/`: heightfield, textures, `slope.pgm`/`flat.pgm` Nav2 maps and `obstacles.json` (rock and boulder geometry used by the benchmark's collision check).

Worlds `<include>` the rover by relative path, which is why the workspace is built with `--merge-install`.
